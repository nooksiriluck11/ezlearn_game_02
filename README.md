# กุกกุกกู๊ (ezlearn_game_02)

เกมฝึกความจำและสมาธิ พร้อมเก็บวลี/สำนวนภาษาอังกฤษไปในตัว — การ์ดคำโผล่มาให้จำว่าคำไหนอยู่ช่องไหน แล้วปิดการ์ด สลับตำแหน่ง และให้ผู้เล่นเรียงประโยคกลับให้ถูกก่อนหมดเวลา

```bash
npm install
npm start
```

กด `w` เปิดบนเบราว์เซอร์ หรือสแกน QR ด้วยแอป **Expo Go** เพื่อเล่นบนมือถือ (มีระบบสั่นตอนนับถอยหลังกับตอนเฉลย เฉพาะบนมือถือ)

| คำสั่ง | ทำอะไร |
| --- | --- |
| `npm start` | dev server ของ Expo |
| `npm run web` | เปิดเฉพาะเว็บ |
| `npm run build` | typecheck + export เว็บ static ลง `dist/` |

## กติกา

1. **จำ** — การ์ดเปิดโชว์คำพร้อมเลขช่อง นับถอยหลัง 5 → 1
2. **ปิด** — การ์ดพลิกคว่ำ เหลือแต่เลขช่อง
3. **สลับ** — รอบท้ายๆ การ์ดจะวิ่งสลับที่ให้เห็น ต้องจ้องตาม
4. **เรียง** — แตะการ์ดตามลำดับประโยค แล้วกด Submit ก่อนหมดเวลา

การ์ดถูกสับตำแหน่งตั้งแต่แจก ไม่มีทางเรียงมาตรงกับประโยค — กด 1-2-3 รัวๆ ไม่มีทางผ่าน

| | ได้อะไร |
| --- | --- |
| วางถูกใบนึง | +20 |
| ถูกทั้งประโยค | +100 และ +50 ต่อการสลับหนึ่งครั้ง |
| กด Skip | −50 ไม่เสียหัวใจ แต่ streak ขาด |
| ตอบผิด / หมดเวลา | เสียหัวใจ 1 ดวง (มี 3 ดวง) |

**ไอเทม** — เริ่มเกมได้ hint 1 ครั้ง (เปิดการ์ดใบที่ต้องใช้ถัดไป) ตอบถูกครบ 3 ข้อได้เพิ่มอีก 1 ส่วนตอบถูกติดกัน 4 ข้อจะได้ไอเทมบวกเวลา +5 วินาที

หมดเวลาแล้วระบบส่งคำตอบเท่าที่วางไว้ให้เอง ยังได้แต้มจากใบที่วางถูก — ตั้งใจให้ยังได้อะไรกลับไปบ้าง ไม่ใช่เสียเปล่า

จบทุกรอบมีหน้าเฉลยบอก**คำแปลไทย**พร้อมป้ายว่าเป็นประโยคธรรมดา วลี หรือสำนวน เพราะครึ่งนึงของคลังคำเป็นสำนวนอังกฤษ (Piece of cake, Once in a blue moon, Actions speak louder than words ฯลฯ) จะได้เก็บสำนวนใหม่ไปด้วยระหว่างเล่น

## ความยาก

ไต่จาก 3 คำ → 4 → 5 และเริ่มสลับตำแหน่งตั้งแต่รอบที่ 4 เวลาตอบค่อยๆ ลดลงจนต่ำสุด 7 วินาที ปรับได้ที่ตาราง `TABLE` ใน `src/game/levels.ts` ที่เดียวจบ

เกมไม่โชว์เลขด่าน เพราะอยากให้โฟกัสที่คะแนนกับ streak มากกว่าการไล่เลเวล

## โครงสร้าง

```
src/
  game/      ตรรกะล้วน ไม่แตะ UI
    useGame.ts   state machine ของหนึ่งรอบ (จำ → ปิด → สลับ → ตอบ → เฉลย)
    levels.ts    ตารางความยาก
    shuffle.ts   สับการ์ดและวางแผนการสลับ
    rewards.ts   กติกาแจก hint / ไอเทมบวกเวลา
    layout.ts    คำนวณตำแหน่งช่องการ์ด
  components/  การ์ด กระดาน นาฬิกา แถบไอเทม หน้าเฉลย
  screens/     หน้าแรกกับหน้าเล่น
  data/        คลังประโยคและสำนวนพร้อมคำแปล
```

การ์ดบนกระดาน render ตามลำดับประโยคเสมอ แล้วขยับด้วย transform ไปยังช่องที่ตัวเองอยู่ — ไม่เรียง DOM ใหม่ตามช่อง เพราะการสลับลำดับ DOM ทำให้ transform ของ Reanimated ค้างอยู่ที่ตำแหน่งเดิม

## Deploy

ต่อ repo นี้กับ Cloudflare Workers Builds ไว้ — push ขึ้น `main` แล้ว deploy เองอัตโนมัติ

`wrangler.jsonc` เป็นตัวคุมทั้งหมด: สั่ง `npm run build` เองก่อน แล้วเสิร์ฟไฟล์ใน `dist/` เป็น static assets จึงไม่ต้องตั้ง build command ในหน้า dashboard
