# kukkukkoo · กุกกุกกู๊ (ezlearn_game_02)

เกมฝึกความจำและสมาธิ พร้อมเก็บวลี/สำนวนภาษาอังกฤษไปในตัว — การ์ดคำโผล่มาให้จำว่าคำไหนอยู่การ์ดเลขอะไร แล้วปิดการ์ด สลับตำแหน่ง และให้ผู้เล่นเรียงประโยคกลับให้ถูกก่อนหมดเวลา

เป็นเว็บ static ล้วน — **Phaser 4** วาดทุกอย่างลงบน canvas เดียว, **Vite** เป็นตัว build, ไม่มี backend ไม่มี framework UI

```bash
npm install
npm run dev
```

เปิด http://localhost:5173 ในเบราว์เซอร์ เล่นได้ทั้งบนคอมและบนมือถือ (บนมือถือมีระบบสั่นตอนนับถอยหลังกับตอนเฉลย ถ้าเครื่องรองรับ)

| คำสั่ง | ทำอะไร |
| --- | --- |
| `npm run dev` | dev server ของ Vite พร้อม hot reload |
| `npm run build` | typecheck + build เว็บ static ลง `dist/` |
| `npm run preview` | เสิร์ฟไฟล์ที่ build แล้ว ไว้เช็คก่อน deploy |

เกมล็อกไว้ที่แนวตั้งเหมือนตอนเป็นแอป ถ้าถือมือถือแนวนอน จะขึ้นข้อความให้หมุนจอแทน

## กติกา

1. **จำ** — การ์ดเปิดโชว์คำพร้อมเลขประจำการ์ด นับถอยหลัง 5 → 1
2. **ปิด** — การ์ดพลิกคว่ำ เหลือแต่เลขประจำการ์ด
3. **สลับ** — รอบท้ายๆ การ์ดจะวิ่งสลับที่ให้เห็น เลขติดไปกับการ์ด ไม่ได้ติดอยู่กับช่อง
4. **เรียง** — แตะการ์ดตามลำดับประโยค แล้วกด Submit ก่อนหมดเวลา

การ์ดถูกสับตำแหน่งตั้งแต่แจก ไม่มีทางเรียงมาตรงกับประโยค — กด 1-2-3 รัวๆ ไม่มีทางผ่าน

**รอบพิเศษ** — ตั้งแต่รอบที่ 3 เป็นต้นไป ประมาณ 30% ของรอบจะเปลี่ยนโจทย์เป็น *"การ์ดใบไหนแปลว่า …"* แทนที่จะให้เรียงทั้งประโยค เลือกแค่ใบเดียวแล้วกด Submit คำถามจะโผล่หลังการ์ดคว่ำแล้วเท่านั้น ไม่งั้นเห็นคำตอบตั้งแต่ตอนจำ และไม่มีรอบพิเศษติดกันสองรอบ

ระบบเลือกเฉพาะคำที่แปลไทยมีความหมายในตัว และไม่ซ้ำกับใบอื่นในรอบนั้น คำอย่าง *the* / *a* จึงไม่ถูกถาม เพราะคำตอบจะกำกวม

| | ได้อะไร |
| --- | --- |
| วางถูกใบนึง | +20 |
| ถูกทั้งประโยค | +100 และ +50 ต่อการสลับหนึ่งครั้ง |
| รอบพิเศษ ตอบถูก | +80 และ +50 ต่อการสลับหนึ่งครั้ง (ตอบผิดได้ 0 เสียหัวใจตามปกติ) |
| กด Skip | −50 ไม่เสียหัวใจ แต่ streak ขาด (ค่าปรับคงที่ ไม่โดนตัวคูณ) |
| ตอบผิด / หมดเวลา | เสียหัวใจ 1 ดวง (ตั้งได้ว่าจะมี 3, 4 หรือ 5 ดวง) |

**ตัวคูณคะแนนตามจำนวนหัวใจ** — เล่นปลอดภัยกว่าก็ควรได้คะแนนน้อยกว่า คะแนนที่ได้ในแต่ละรอบเลยคูณตามนี้

| หัวใจ | ตัวคูณ | ประโยค 3 คำถูกหมด | ประโยค 5 คำ สลับ 2 ครั้ง |
| --- | --- | --- | --- |
| 3 | ×1 | 160 | 300 |
| 4 | ×0.85 | 136 | 255 |
| 5 | ×0.7 | 112 | 210 |

3 ดวงเป็นฐาน ×1 เพราะสถิติเก่าทั้งหมดทำไว้ตอนที่เกมมี 3 ดวงอย่างเดียว คะแนนเก่ากับใหม่จะได้เทียบกันได้ ตัวคูณอยู่ที่ `scoreMultiplier()` ใน `src/game/rewards.ts`

**ไอเทม** — มีสามอย่าง แจกตามนี้ ปรับได้ที่ `src/game/rewards.ts`

| ไอเทม | ทำอะไร | เริ่มมี | ได้เพิ่มเมื่อ |
| --- | --- | --- | --- |
| **Hint** | เปิดการ์ดใบที่ต้องใช้ถัดไป | 1 | ตอบถูกครบทุก 3 ข้อ (นับสะสม ไม่ต้องติดกัน) |
| **+5s** | ต่อเวลาตอบอีก 5 วินาที | 0 | ตอบถูกติดกัน 4 ข้อ |
| **Unshuffle** | ดึงการ์ดกลับไปเรียงตามตำแหน่งตอนแจก ล้างการสลับของรอบนั้นทิ้ง | 1 | ตอบถูกติดกัน 3 ข้อ |

ในเกมดูได้จากปุ่ม **Bonus items** มุมขวาบนของหน้าแรก เด้งเป็นแผงแบบเดียวกับตั้งค่า ข้อความในแผงสร้างจากค่าคงที่ใน `rewards.ts` ตรงๆ แก้กติกาแล้วแผงเปลี่ยนตาม ไม่ต้องไล่แก้สองที่

Unshuffle กดได้เฉพาะตอนที่การ์ดถูกสลับไปแล้วจริงๆ รอบที่ไม่มีการสลับปุ่มจะเทาไว้ ไม่ให้เสียของฟรี ตอบผิดหรือกด Skip เมื่อไหร่ streak ขาด ต้องไล่ 3 ข้อติดใหม่

หมดเวลาแล้วระบบส่งคำตอบเท่าที่วางไว้ให้เอง ยังได้แต้มจากใบที่วางถูก — ตั้งใจให้ยังได้อะไรกลับไปบ้าง ไม่ใช่เสียเปล่า

จบทุกรอบมีหน้าเฉลยบอก**คำแปลไทย**พร้อมป้ายว่าเป็นประโยคธรรมดา วลี หรือสำนวน เพราะครึ่งนึงของคลังคำเป็นสำนวนอังกฤษ (Piece of cake, Once in a blue moon, Actions speak louder than words ฯลฯ) จะได้เก็บสำนวนใหม่ไปด้วยระหว่างเล่น

## ตั้งค่า

มุมขวาบนของหน้าแรกมีสองปุ่ม — **Bonus items** อธิบายไอเทม และฟันเฟือง **⚙** เปิดแผงตั้งค่า ทั้งคู่ใช้โครงแผงเดียวกัน (`src/ui/panels.ts`) กดฟันเฟืองแล้วจะเด้งแผงตั้งค่าขึ้นมา แบ่งเป็นสามกลุ่ม CARDS / DIFFICULTY / SOUND ปิดได้ทั้งปุ่ม Done ปุ่ม ✕ หรือแตะพื้นที่มืดรอบๆ ค่าที่ตั้งเก็บลงเครื่องให้เอง เปิดเกมครั้งหน้าค่าเดิมยังอยู่

| ตั้งค่า | ทำอะไร |
| --- | --- |
| **Thai on cards** | โชว์คำแปลไทยใต้คำอังกฤษบนการ์ด (แปลทีละคำ คำที่ไม่มีความหมายเดี่ยวๆ อย่าง *the* จะขึ้น `—`) |
| **Part of speech** | โชว์ชนิดของคำเหนือคำอังกฤษ — NOUN VERB ADJ ADV PRON PREP CONJ DET AUX ตามหน้าที่ของคำนั้นในประโยคนั้นจริงๆ |
| **Card numbers** | ปิดแล้วการ์ดไม่มีเลขเลย ทั้งด้านหน้าและด้านหลัง ตอนสลับต้องจ้องตามการ์ดเอาเอง ยากขึ้นอีกขั้น |
| **Memorize time** | เลือกเวลานับถอยหลังตอนจำ 5 / 7 / 10 วินาที |
| **Hearts** | เลือกจำนวนหัวใจต่อหนึ่งรอบเล่น 3 / 4 / 5 ดวง — ยิ่งน้อยยิ่งได้ตัวคูณคะแนนสูง |
| **Sound effects** | เสียงนับถอยหลัง พลิกการ์ด สลับการ์ด สัญญาณเริ่มตอบ เสียงเร่งช่วง 3 วินาทีสุดท้าย และเสียงเฉลย ปิดได้ถ้าไม่อยากให้มีเสียง |

ปิดเลขการ์ดแล้วช่องคำตอบจะขึ้นเป็นจุด `●` แทน `#3` ส่วนเลขลำดับที่กดไปแล้วยังโชว์บนการ์ดเหมือนเดิม จะได้รู้ว่ากดไปกี่ใบ

เปิดสองตัวแรกพร้อมกัน การ์ดจะอ่านเหมือนหน้าดิกชันนารี — ชนิดคำ / คำอังกฤษ / คำแปล เหมาะกับคนที่อยากเก็บศัพท์มากกว่าจะเอาความยาก

กลางเกมมีปุ่ม **✕** มุมซ้ายบน เผื่อเล่นต่อไม่ไหวแล้ว กดแล้วถามยืนยันก่อนหนึ่งที ระหว่างถามนาฬิกาหยุดเดินให้ และการ์ดโดนบังไว้ไม่ให้แอบดู ถ้ากด Quit คะแนนที่เก็บมาได้ยังถูกบันทึกเป็นสถิติตามปกติ ไม่ได้หายไปเปล่าๆ

เสียงทั้งหมดสังเคราะห์เองด้วย `python3 tools/make-sfx.py` ไฟล์ออกมาที่ `public/sfx/` เป็นโน้ตในคีย์ C เมเจอร์ เสียงกังวานแบบระนาด/ระฆังเล็ก มีหางเสียงนิดหน่อยให้ฟังนุ่ม ไม่ใช่เสียงบี๊บแข็งๆ อยากเปลี่ยนโน้ตหรือโทนก็แก้ในสคริปต์แล้วรันใหม่

## ความยาก

ไต่จาก 3 คำ → 4 → 5 และเริ่มสลับตำแหน่งตั้งแต่รอบที่ 4 เวลาตอบค่อยๆ ลดลงจนต่ำสุด 7 วินาที ปรับได้ที่ตาราง `TABLE` ใน `src/game/levels.ts` ที่เดียวจบ

ยกเว้นเวลาจำ — อันนั้นผู้เล่นเลือกเองในหน้าตั้งค่า ค่าที่เลือกทับค่าในตารางทุกด่าน

เกมไม่โชว์เลขด่าน เพราะอยากให้โฟกัสที่คะแนนกับ streak มากกว่าการไล่เลเวล

## ฟอนต์

ใช้ **Prompt** ทั้งเกม เก็บไฟล์ไว้เองที่ `public/fonts/` (woff2 เฉพาะ subset latin กับ thai น้ำหนักละไฟล์ รวม 8 ไฟล์ ~68 KB) ไม่ยิงไป Google Fonts ตอนเล่น

`src/main.ts` รอ `document.fonts.load()` ให้เสร็จก่อนค่อยสร้างเกม เพราะ Phaser วัดความกว้างข้อความด้วย Canvas API — ถ้าฟอนต์ยังไม่มา มันจะวัดจากฟอนต์ระบบแล้วขนาดการ์ดจะเพี้ยน และต้องสั่งโหลดด้วยตัวอย่างตัวอักษรทั้งไทยและอังกฤษ ไม่งั้น subset ไทยจะไม่ถูกดึงมา

Phaser วัดความสูงบรรทัดจาก `testString` ไม่ใช่จากข้อความจริง ค่าที่ตั้งไว้ใน `src/ui/kit.ts` เลยใส่สระบนกับวรรณยุกต์ไทยไว้ด้วย ไม่งั้นหัวตัวอักษรอย่าง ก๊ จะโดนตัด

ขนาดตัวอักษรบนการ์ดคิดจากค่า `CHAR_EM` ใน `src/game/layout.ts` ซึ่งวัดจาก Prompt Black มาแล้ว (0.53 ต่อตัวสำหรับตัวพิมพ์เล็ก, 0.61 สำหรับตัวใหญ่) เปลี่ยนฟอนต์เมื่อไหร่ต้องวัดใหม่

## โครงสร้าง

```
index.html   หน้าเดียวจบ + CSS ของหน้าจอ "หมุนจอ"
src/
  main.ts    รอฟอนต์ → สร้าง Phaser.Game → คอยปรับขนาด canvas
  game/      ตรรกะล้วน ไม่แตะการวาด
    engine.ts    state machine ของหนึ่งรอบ (จำ → ปิด → สลับ → ตอบ → เฉลย)
    levels.ts    ตารางความยาก
    shuffle.ts   สับการ์ดและวางแผนการสลับ
    rewards.ts   กติกาแจก hint / บวกเวลา / unshuffle
    layout.ts    ตำแหน่งช่องการ์ดกับขนาดตัวอักษรบนการ์ด
  scenes/    BootScene โหลดเสียง · HomeScene หน้าแรก · GameScene หน้าเล่น
  ui/        viewport.ts ระบบพิกัด/ความคมชัด · kit.ts ปุ่มกับกล่อง · CardView.ts การ์ด · panels.ts แผง popup
  audio/     sfx.ts เล่นเสียงผ่าน SoundManager ของ Phaser
  storage/   progress.ts คะแนนสูงสุด · settings.ts สวิตช์ตั้งค่า (localStorage)
  appState.ts  ค่าตั้งค่า สถิติ และผลรอบล่าสุด ที่อยู่ข้ามฉาก
  data/      คลังประโยคและสำนวน พร้อมคำแปลทั้งประโยค คำแปลทีละคำ และชนิดของคำ
public/
  sfx/       ไฟล์เสียง .wav ที่สร้างจาก tools/make-sfx.py
  fonts/     Prompt woff2 + prompt.css
```

`engine.ts` ไม่รู้จัก Phaser เลยนอกจาก EventEmitter — มันยิง event (`round` `phase` `slots` `answer` `hud` `clock` `result` `gameover`) แล้ว `GameScene` เป็นคนวาดกับเล่นเสียงตาม ตัวจับเวลารับมาจากข้างนอกเป็น `Scheduler` ซึ่ง `GameScene` ต่อเข้ากับนาฬิกาของฉาก รอบจึงหยุดตามฉากและตายไปพร้อมฉาก

การ์ดหนึ่งใบเป็น container ซ้อนกันสามชั้น — ชั้นนอกเลื่อนระหว่างช่อง ชั้นกลางยกขึ้นตอนถูกเลือก ชั้นในบีบแกน X ตอนพลิก แต่ละการเคลื่อนไหวจึงไม่ทับกันเอง

**ความคมบนจอ retina** — Phaser โหมด `RESIZE` จะให้ canvas เท่ากับ CSS pixel ซึ่งบนมือถือคือวาดที่ความละเอียดครึ่งเดียวของจอ เกมนี้เลยใช้โหมด `NONE` + `zoom: 1/DPR` ให้ canvas ใหญ่เป็น device pixel แล้วบีบกลับด้วย CSS ส่วนกล้องของแต่ละฉาก zoom เท่า DPR โค้ดวางเลย์เอาต์จึงยังคิดเป็น CSS pixel ตามปกติ (`src/ui/viewport.ts`)

## Deploy

ต่อ repo นี้กับ Cloudflare Workers Builds ไว้ — push ขึ้น `main` แล้ว deploy เองอัตโนมัติ

`wrangler.jsonc` เป็นตัวคุมทั้งหมด: สั่ง `npm run build` เองก่อน แล้วเสิร์ฟไฟล์ใน `dist/` เป็น static assets จึงไม่ต้องตั้ง build command ในหน้า dashboard
